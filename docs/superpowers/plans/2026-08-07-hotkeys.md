# Hotkeys Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a global summon hotkey, focus-search-on-open, and ⌘/Ctrl+1–5 quick-copy to both the 2FAU desktop app and browser extension.

**Architecture:** The quick-copy handler, the row flash/badge, and the search-focus logic live once in the shared `@twofau/ui` package (drives both the extension popup and the desktop webview). Two host-specific props are threaded through (`requestClose`, `focusNonce`). The desktop gains a Rust global shortcut via `tauri-plugin-global-shortcut`; the extension already has its summon command in the manifest.

**Tech Stack:** React 19 · Vitest + @testing-library · Tauri 2 (Rust) · `tauri-plugin-global-shortcut` v2.

## Global Constraints

- The UI never imports Tauri APIs — host I/O goes through props (`requestClose`, `focusNonce`, `writeClipboard`). (`CLAUDE.md`)
- Every behaviour change gets a test: Vitest for `@twofau/ui`. (`CLAUDE.md`)
- Interactive tray/popup/global-shortcut behaviour cannot be verified headlessly — report it as manually GUI-verified, never claim a headless "confirmed". (`CLAUDE.md`)
- Conventional commits (`feat:`, `fix:`, `chore:`), scope optional.
- Copy binding is `⌘/Ctrl + Digit1..5`; mapping is the displayed order `[...matched, ...rest]` first 5; after copy → flash then dismiss.
- Desktop summon key is fixed **CmdOrCtrl+Shift+U** (matches the extension). Rust-side shortcut registration needs **no** capability permission (capabilities gate only the webview→command bridge).
- Full verify before done: `cargo fmt --check && cargo clippy --all-targets -D warnings && cargo test && pnpm -r test && pnpm -r typecheck` (`docs/DEVELOPMENT.md § Verify`).

All commands run from the repo root `~/Projects/2fau-tauri` unless noted. UI tests: `pnpm --filter @twofau/ui test`.

```tsx
  // ⌘/Ctrl+1..5 copies the Nth displayed account's code, flashes it, then asks
  // the host to dismiss. A modifier is required so it never collides with the
  // auto-focused search box.
  useEffect(() => {
    function onKey(e: KeyboardEvent) {
      if (!(e.metaKey || e.ctrlKey) || e.altKey || e.shiftKey) return;
      const m = /^Digit([1-5])$/.exec(e.code);
      if (!m) return;
      const target = displayed[Number(m[1]) - 1];
      if (!target) return;
      const raw = codes[target.id] ?? "";
      if (!raw) return;
      e.preventDefault();
      void writeText(raw);
      setFlashId(target.id);
      window.setTimeout(() => setFlashId(null), 1000);
      window.setTimeout(() => requestClose?.(), 600);
    }
    window.addEventListener("keydown", onKey);
    return () => window.removeEventListener("keydown", onKey);
  }, [displayed, codes, writeText, requestClose]);
```
