# i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the app, extension, and marketing site translatable from one shared `@twofau/i18n` package using English-as-key `t()`, add language selection, and ship machine translations for 12 languages.

**Architecture:** A custom tiny runtime (`t(source, vars?)`, `plural(count, forms, vars?)`, identity English fallback, `Intl.PluralRules`) in `@twofau/i18n`, consumed by the shared React UI via `I18nProvider`/`useT()` (app + extension) and by the Astro site via a server `getT(Astro.currentLocale)` with i18n routing. The extension manifest is localized via generated `_locales`. Every user-facing string becomes `t('English')`; an `extract-i18n` script builds the `en` source catalog and syncs locale files.

**Tech Stack:** TypeScript, React 19, Astro (i18n routing), Tauri, Vite, Vitest, pnpm workspace, `Intl.PluralRules`, web-extension `_locales`.

**Spec:** `docs/superpowers/specs/2026-09-07-i18n-design.md`

## Global Constraints

- **English-as-key:** the key IS the English source string — `t('Auto-Lock')`, `t("Passwords don't match.")`, `t('{count} minutes', { count })`, `plural(count, { one: '1 minute', other: '{count} minutes' })`. Never invent dot-path ids. Missing key ⇒ render the source (identity fallback).
- **12 locales:** `en` (source), `zh-CN`, `es`, `pt-BR`, `ja`, `de`, `fr`, `ru`, `ko`, `it`, `tr`, `pl`. `DEFAULT_LOCALE = 'en'`.
- **Namespaces (by surface, for bundling):** `ui` (app + extension + shared UI), `site` (marketing), `store` (extension manifest — keyed by short ids, not English, because `__MSG_*__` must be identifiers).
- **English is never bundled as a locale file** in consumers — it's the identity fallback; only the active non-English locale loads (dynamic import).
- **`@twofau/ui` must not import Tauri/chrome APIs** (existing invariant) — locale I/O goes through the `SettingsBackend` port.
- Branch `feat/i18n`; every task is one atomic Conventional Commit `feat(i18n): …` (tooling/docs may use `chore(i18n):`/`docs(i18n):`). No Co-Authored-By trailers (user preference).
- Verify before done: `pnpm -r typecheck`, `pnpm -r test`, `pnpm --filter @twofau/site build`, extension `web-ext lint`.

- [ ] **Step 4: Write `locales.ts`**

`packages/i18n/src/locales.ts`:
```ts
export const DEFAULT_LOCALE = "en";

/** Order = display order in selectors. */
export const SUPPORTED_LOCALES = [
  "en", "zh-CN", "es", "pt-BR", "ja", "de", "fr", "ru", "ko", "it", "tr", "pl",
] as const;

export type Locale = (typeof SUPPORTED_LOCALES)[number];

/** Endonyms (name of the language in that language). */
export const LOCALE_NAMES: Record<Locale, string> = {
  en: "English",
  "zh-CN": "简体中文",
  es: "Español",
  "pt-BR": "Português (Brasil)",
  ja: "日本語",
  de: "Deutsch",
  fr: "Français",
  ru: "Русский",
  ko: "한국어",
  it: "Italiano",
  tr: "Türkçe",
  pl: "Polski",
};

/** Map a BCP-47 tag to a supported locale, else DEFAULT_LOCALE.
 * Tries exact, then language-only (first supported locale with that language). */
export function resolveLocale(tag?: string | null): Locale {
  if (!tag) return DEFAULT_LOCALE;
  const norm = tag.trim();
  const exact = SUPPORTED_LOCALES.find((l) => l.toLowerCase() === norm.toLowerCase());
  if (exact) return exact;
  const lang = norm.split("-")[0].toLowerCase();
  const byLang = SUPPORTED_LOCALES.find((l) => l.split("-")[0].toLowerCase() === lang);
  return byLang ?? DEFAULT_LOCALE;
}
```

- [ ] **Step 5: Write `index.ts` (core runtime)**

`packages/i18n/src/index.ts`:
```ts
export * from "./locales";
export { loadMessages } from "./load";

export type PluralForms = Record<string, string>;
export type Messages = Record<string, string | PluralForms>;
export type Vars = Record<string, string | number> & { _ctx?: string };

const CTX = ""; // gettext msgctxt separator

function interpolate(template: string, vars?: Vars): string {
  if (!vars) return template;
  return template.replace(/\{(\w+)\}/g, (_, k) => {
    const v = vars[k];
    return v == null ? `{${k}}` : String(v);
  });
}

export function createTranslator(locale: string, messages: Messages) {
  const t = (source: string, vars?: Vars): string => {
    const ctxKey = vars?._ctx ? `${vars._ctx}${CTX}${source}` : null;
    const hit =
      (ctxKey && messages[ctxKey]) != null ? messages[ctxKey!] : messages[source];
    const template = typeof hit === "string" ? hit : source;
    return interpolate(template, vars);
  };

  const plural = (count: number, forms: PluralForms, vars?: Vars): string => {
    const cat = new Intl.PluralRules(locale).select(count); // "one" | "other" | ...
    const entry = messages[forms.other]; // catalog key is the English `other` form
    const table: PluralForms =
      entry && typeof entry === "object" ? (entry as PluralForms) : forms;
    const template = table[cat] ?? table.other ?? forms.other;
    return interpolate(template, { count, ...vars });
  };

  return { t, plural, locale };
}
```

- [ ] **Step 6: Write `load.ts`**

`packages/i18n/src/load.ts`:
```ts
import { DEFAULT_LOCALE, type Locale } from "./locales";
import type { Messages } from "./index";

export type Namespace = "ui" | "site" | "store";

/** Load one locale+namespace catalog. English is the identity fallback, so it
 * resolves to `{}` (no file needed). Missing files resolve to `{}` too. */
export async function loadMessages(locale: string, ns: Namespace): Promise<Messages> {
  if (locale === DEFAULT_LOCALE) return {};
  try {
    const mod = await import(`../locales/${locale as Locale}/${ns}.json`);
    return (mod.default ?? mod) as Messages;
  } catch {
    return {};
  }
}
```

import { createContext, useContext, useMemo, type ReactNode } from "react";
import { createTranslator, type Messages } from "./index";
import { DEFAULT_LOCALE } from "./locales";

const Ctx = createContext(createTranslator(DEFAULT_LOCALE, {}));

export function I18nProvider({
  locale,
  messages,
  children,
}: {
  locale: string;
  messages: Messages;
  children: ReactNode;
}) {
  const value = useMemo(() => createTranslator(locale, messages), [locale, messages]);
  return <Ctx.Provider value={value}>{children}</Ctx.Provider>;
}

/** Returns { t, plural, locale } bound to the active locale. */
export function useT() {
  return useContext(Ctx);
}

```ts
import { createTranslator } from "@twofau/i18n";
import en from "@twofau/i18n/locales/en/site.json";
// Static glob import so every locale is bundled for SSG.
const catalogs = import.meta.glob("../../../../packages/i18n/locales/*/site.json", { eager: true });
export function getT(locale: string | undefined) {
  const loc = locale ?? "en";
  const mod = catalogs[`../../../../packages/i18n/locales/${loc}/site.json`] as any;
  const messages = loc === "en" ? {} : (mod?.default ?? {});
  return createTranslator(loc, messages).t;
}
```
